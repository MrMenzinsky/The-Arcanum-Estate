# Foundation Mod: The Arcanum Estate — Project Brief

Last updated: June 3, 2026

**Current milestone:** Pre-production / Design Phase — Core Estate Structure & Identity. Also started on the Lua code and some 3D modeling for the core monument.

### What This Game Is

A comprehensive mod expanding the base city-builder Foundation (made by the game studio Polymorph Games) by introducing a fourth, distinct social class: **The Arcanum Estate**. The mod allows players to cultivate a society of scholars and magic-users (Aetherians), harvest unique arcane resources, and construct grand, geometrically inspired monuments. The core fantasy is managing the intersection of medieval science, academic study, and high magic within a thriving settlement.

### Tech Stack

* **Engine:** Foundation Custom Engine called Hurricane (I think?) and has an official modding API that supports Lua scripting for game logic and behavior.
* **Language:** Lua (Standard for Foundation mods)
* **Version control:** Git (remote: GitHub)
* **Asset pipeline:** Blender → .fbx model files for 3D assets, vanilla game textures provided by the developers for modders to use, and other art generated by AI tools and then manually retouched in Krita.
* **Other tools:** VS Code for Lua scripting, GitHub Projects for task management, and Discord for community engagement and feedback. Open for trying Obsidian for design documentation to help with organization.

### Design Principles / Non-Negotiables

* **Visual Distinction:** The Arcanum must feel inherently different from vanilla estates; less rugged/regal, more intellectual and constructed.
* **Architectural Language:** Core monuments might have some geometric shapes (icosahedrons, domes, formalized nodes) mixed in with standard medieval architecture to get its unique feel.
* **Thematic Needs:** High-tier units require sophisticated needs (e.g., *Discourse* via advanced lectures) rather than standard physical entertainment.
* **Heraldry Silhouette:** Must utilize the "Flared Top / Sharp Base" shield shape to convey a dynamic, high-magic, and specialized seal.
