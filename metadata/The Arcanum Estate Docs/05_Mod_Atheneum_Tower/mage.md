# Mage

**Mage / High Mage / Grand Mage / Archmage** is the Mage specialization status progression. Mages choose one of four elemental work professions (Wind Weaver, Stone Shaper, Flame Forger, Mist Maker) upon promoting from Arcanist.

For full context, see [[mage-design]].
