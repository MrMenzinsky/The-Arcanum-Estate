# Atheneum Tower Decorations

Per-path decoration palette for the **Mage path** — elemental, scientific, structured. Status `design-captured-deferred` since expansion-mod work is out of scope for the current milestone; this roster is here so the design isn't lost. Same naming-convention caveat as [[aethercourt-decorations]] applies: candidate names use status/job prefixes that may be reworked when the convention is locked.

## Tier 3 — Initiation

| Decoration | Description |
| --- | --- |
| **Wind Chime Array** | Intricate metallic chimes that sway and catch atmospheric currents studied by [[wind-weaver\|Wind Weavers]]. |
| **Stone Shaper's Block** | Half-carved granite block on a sturdy wooden table, surrounded by precise chisels — [[stone-shaper]] working surface. |
| **Apprentice's Astrolabe** | Modest brass tool on a stone plinth for mapping early celestial alignments. |

## Tier 4 — Mastery

| Decoration | Description |
| --- | --- |
| **Flame Forger's Brazier** | Contained perpetually-burning iron brazier for volatile creation and heat manipulation — [[flame-forger]] anchor decoration. **Requires vertex-color / HDR-RGBA emissive workaround.** |
| **Mist Maker's Basin** | Shallow ornate stone pool that continuously spills decorative vapor over its edges — [[mist-maker]] anchor decoration. |
| **Elemental Focusing Crystal** | Distinctly colored, highly faceted Aether Crystal on a metallic stand to channel specific elemental energies. |

## Tier 5 — Apex

| Decoration | Description |
| --- | --- |
| **Elemental Convergence Sphere** | Hovering multifaceted crystal sphere representing mastery of the four elements. |
| **Archmage's Orrery** | Massive intricately-detailed brass astronomical instrument centerpiecing the Tower's highest courtyard. |

## Notes

- The four elemental jobs ([[flame-forger]], [[mist-maker]], [[stone-shaper]], [[wind-weaver]]) each get a thematic T3/T4 anchor decoration.
- The "Hovering" Elemental Convergence Sphere uses the anti-gravity principle established by the [[artificer|Artificer]] charged-container pivot.
- **Archmage** is the T5 Mage mastery rank name (triple-cited: NotebookLM report + chat decoration + [[arch-mage]] vault note).
- Per-path charged-container variants for the Mage path: [[arcane-fire-anchorstone]], [[arcane-wind-anchorstone]], [[arcane-earth-anchorstone]], [[arcane-water-anchorstone]].
