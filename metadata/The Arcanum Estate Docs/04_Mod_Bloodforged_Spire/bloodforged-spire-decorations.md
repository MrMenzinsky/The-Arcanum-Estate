# Bloodforged Spire Decorations

Per-path decoration palette for the **Sorcerer path** — innate, ritual, summoning. Status `design-captured-deferred`. Same naming-convention caveat as [[aethercourt-decorations]].

## Tier 3 — Initiation

| Decoration | Description |
| --- | --- |
| **Chalk Ritual Circle** | Complex esoteric summoning circle drawn hastily in dirt or on paving stones. |
| **Familiar's Perch** | Twisted dark wood stand designed as a resting place for summoned creatures and mystical beasts. |
| **Scattered Reagents Table** | Messy unstructured workbench covered in rare bones, dark inks, and strange vials. |

## Tier 4 — Mastery

| Decoration | Description |
| --- | --- |
| **Incantator's Altar** | Dark stone slab stained with arcane reagents, used for forging formal covenants and binding rituals. |
| **Floating Blood-Crystal** | Jagged crimson-hued faceted crystal suspended in mid-air by the erratic energy of the Spire. |
| **Bound-Spirit Lantern** | Heavy iron lantern containing a swirling, chaotic, colorful magical anomaly instead of a flame. **Glow via vertex-color workaround.** |

## Tier 5 — Apex

| Decoration | Description |
| --- | --- |
| **Supreme Binding Obelisk** | Dark monolithic pillar etched with glowing chaotic runes representing absolute mastery over summoned entities. **Glow via vertex-color workaround.** |
| **Void-Tear Fissure** | Decorative floor piece resembling a localized stable rupture in reality where raw unstructured magic leaks through. |

## Notes

- **Incantator** is the Sorcerer's primary T3 profession from the Phase 1 NotebookLM report finding.
- **Supreme Sorcerer** is implied as the T5 mastery rank (Supreme Binding Obelisk framing).
- **Floating Blood-Crystal** is the Sorcerer's per-path charged-container variant analogue — see [[arcane-blood-anchorstone]]. **However**, this decoration uses the *Crystal* line ("Floating Blood-Crystal") while the corresponding resource note uses the *Anchorstone* line. **This is the cross-mod naming inconsistency to resolve** — see [[master-to-do]] and [[dh-notebooklm-charged-containers]]. The decoration name will need to change to match whichever line wins.
- Multiple "glowing" decorations require the vertex-color / HDR-RGBA emissive workaround.
