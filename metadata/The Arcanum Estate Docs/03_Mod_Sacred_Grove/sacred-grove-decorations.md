# Sacred Grove Decorations

Per-path decoration palette for the **Druid path** — nature, life, ancient wisdom. Status `design-captured-deferred`. Same naming-convention caveat as [[aethercourt-decorations]].

## Tier 3 — Initiation

| Decoration | Description |
| --- | --- |
| **Root-Bound Bench** | Resting place naturally shaped from thick living roots of surrounding ancient trees. |
| **Herb-Drying Rack** | Rustic wooden frame hung with bundles of rare herbs and magical blooms cultivated by Rootshapers. |
| **Mossy Cairn** | Small weathered pile of stones serving as a quiet marker for ancient nature spirits. |

## Tier 4 — Mastery

| Decoration | Description |
| --- | --- |
| **Crystal-Fused Roots** | Massive gnarled tree roots that have naturally grown around and encapsulated large Faceted Aether Crystals. |
| **Offering Stone** | Moss-covered boulder where natural offerings and gathered essences are laid out for ancient rituals. |
| **Luminous Fungi Cluster** | Large glowing mushrooms thriving in the deep magical shade of the Evertree canopy. **Glow via vertex-color workaround.** |

## Tier 5 — Apex

| Decoration | Description |
| --- | --- |
| **Ancient Evertree Sapling** | Glowing, magically dense sapling representing the profound life-giving power of the Earthparent. **Glow via vertex-color workaround.** |
| **Primal Monolith** | Towering unhewn menhir covered in ancient glowing moss that hums with the deep magic of the earth. **Glow via vertex-color workaround.** |

## Notes

- **Earthparent** is the T5 Druid mastery rank name (triple-cited).
- **Rootshaper** is the Druid's primary T3 profession from the Phase 1 NotebookLM report finding.
- **Evertree** appears as both a top-tier life-tree and (in [[master-to-do]] forgotten-items) a deferred signature tree-building inside the Sacred Grove. The "Ancient Evertree Sapling" decoration is the smaller decorative cousin of that signature building.
- **Aetherwood** species ([[aether-bloom-garden]] forgotten-item) is the source material for the Evertree imagery; an upgrade path from T2 Aetherwood Sapling decoration ([[aethercourt-decorations|in Aethercourt]]) to T5 Ancient Evertree Sapling is implicit.
- Multiple "glowing" decorations require the vertex-color / HDR-RGBA emissive workaround.
- Per-path charged-container variant: [[arcane-life-anchorstone]] (modifier `[TBD]`).
