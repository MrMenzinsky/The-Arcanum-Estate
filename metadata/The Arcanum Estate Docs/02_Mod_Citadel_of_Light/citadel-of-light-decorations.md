# Citadel of Light Decorations

Per-path decoration palette for the **Paladin path** — holy, martial, defensive. Status `design-captured-deferred`. Same naming-convention caveat as [[aethercourt-decorations]].

## Tier 3 — Initiation

| Decoration | Description |
| --- | --- |
| **Paladin's Weapon Rack** | Sturdy wooden frame holding polished shields and halberds for the Citadel's defenders. |
| **Vigilant's Brazier** | Tall wrought-iron torch stand designed to light the defensive perimeters. **Requires vertex-color / HDR-RGBA emissive workaround.** |
| **Initiate's Kneeling Mat** | Simple woven mat placed before a small stone shrine for holy reflection. |

## Tier 4 — Mastery

| Decoration | Description |
| --- | --- |
| **Consecrated Banners** | Tall majestic flags bearing the bright holy symbols of the Paladin order. |
| **Divine Seal Pedestal** | Stone pillar displaying a glowing, masterfully forged [[divine-seal]] as testament to the [[reliquary-smith\|Reliquary Smiths]]. **Glow via vertex-color workaround.** |
| **Holy Armament Display** | Decorative suit of consecrated plate armor standing sentinel near the [[sanctum]] entrance. |

## Tier 5 — Apex

| Decoration | Description |
| --- | --- |
| **Hallow Lord's Statue** | Towering marble carving of an ancient revered Paladin holding a protective aegis. |
| **Radiant Anchorstone** | Uniquely charged golden anchorstone hovering above the Citadel entrance to project an aura of safety. |

## Notes

- **Hallow Lord** is the T5 Paladin mastery rank name (triple-cited).
- **Radiant Anchorstone** is the Paladin's per-path charged-container variant — see [[arcane-radiant-anchorstone]]. Concrete example of the [[artificer|Artificer]] pivot's per-monument infusion model.
- Most decorations here involve "glowing" / "bright" elements that require the vertex-color / HDR-RGBA emissive workaround per [[3d-modeling-pipeline#Emissive treatment — vertex colors / HDR-RGBA (no light sources)]].
- **Divine Seal Pedestal** ties to the existing [[reliquary-smith]] job + Divine Forge workplace from the [[dh-paladin-workplaces]] design.
