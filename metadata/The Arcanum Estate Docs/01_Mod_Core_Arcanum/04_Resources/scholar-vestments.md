# Scholar's Vestments

**Scholar's Vestments** is a Tier-2 consumable / good. Produced at the [[arcane-weaver|Arcane Weaver]] by Serfs / Commoners combining vanilla **Cloth** (Labor Estate) with **Aether Crystal Dust** (Lapidary byproduct).

The use of Aether Crystal Dust rather than Glyphs is a deliberate choice — physical material infusion is thematically more logical for clothing than consuming an abstract intellectual resource.

For full context, see [[core-economy]].
