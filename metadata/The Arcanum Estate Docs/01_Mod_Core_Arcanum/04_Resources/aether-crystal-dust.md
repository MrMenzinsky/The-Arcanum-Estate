# Aether Crystal Dust

**Aether Crystal Dust** is a Tier-2 byproduct of the [[lapidary|Lapidary]]. Produced alongside Faceted Aether Crystals when Lapidarists refine raw Aether Crystal — the Lapidary uses the engine's dual-resource workplace logic (Apiary pattern: Wax + Honey).

Consumed at the [[arcane-weaver|Arcane Weaver]] as one of the two inputs for [[scholar-vestments|Scholar's Vestments]] (the other being vanilla Cloth). Keeping the Lapidary economically relevant even after monument construction is done — Dust is the sink that ensures Lapidarists don't run out of useful work.

For full context, see [[core-economy]]. Engine-level dual-output verification task: see [[master-to-do]] Lua / code section.
