# Aetherial Elixir

**Aetherial Elixir** is a Tier-2 consumable / buff item. Brewed at the [[apothecary|Apothecary]] by combining [[aether-bloom|Aether Blooms]] (cultivated in the [[aether-bloom-garden|Aether Bloom Garden]]) with vanilla **Berries / Herbs** (Labor / Clergy estates).

Bridges the Arcanum magical economy with standard village agricultural production.

For full context, see [[core-economy]].
