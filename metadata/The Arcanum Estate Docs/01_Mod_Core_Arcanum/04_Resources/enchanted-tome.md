# Enchanted Tome

**Enchanted Tome** is the Arcanum Estate's Tier-4 high-value trade good. Produced by Tomebinders (Loremasters) at the [[aether-bindery|Aether Bindery]] from **Glyphs + Planks + Faceted Aether Crystals**. Exported via trade routes for gold, not consumed by the estate's own villagers.

Deliberately uses Tier-1 **Glyphs** rather than Tier-2 Arcane Lore — keeps the promotion economy unstrained (Arcane Lore is reserved for promotions to specialists and Loremasters). A playtest-driven swap to Arcane Lore is an open balancing option if Glyphs end up over-abundant late-game.

For full context, see [[core-economy]].
