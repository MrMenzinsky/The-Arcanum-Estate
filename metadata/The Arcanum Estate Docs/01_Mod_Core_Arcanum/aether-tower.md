# Aether Tower

**Aether Tower** was the working name for the Mage sub-building inside the Aethercourt during early design. The name has been retired — the Mage path's architectural anchor is now the Tier-3 monument **[[atheneum-tower|Atheneum Tower]]** instead. Kept here as a redirect for anyone searching the old name.

For full context, see [[abandoned-ideas]].
