# Aethercourt Decorations

The Aethercourt's decorations are deliberately **foundational, unspecialized, and academic** — the four specialization monuments lean into their specific magical domains (see each expansion-mod's decorations note). Status `design-iterating` because the **decoration naming convention itself is unresolved** — see [[master-to-do]] forgotten-items.

> [!IMPORTANT] Naming convention pending
> The candidate names below use the old `Rustic` prefix and status/job names (`Aspirant's Chalkboard`, `Loremaster's Lectern`). The vault has since locked `Scholastic` (T1+T2) and `Arcane` (T3+ core) prefixes for **building parts** and explicitly rejected status/job prefixes there. Whether decorations follow the same rule, or use one of the three candidate conventions Anton flagged (core-mod progression / vanilla Common / vanilla estate), is `[TBD]`. The names below are NotebookLM-suggested rosters captured as paper trail; **final names will change** once the convention is picked.

## Tier 1 — Aspirant level (rustic, academic, slightly wild)

| Decoration | Description |
| --- | --- |
| **Rustic Scholar's Bench** | Simple wooden bench with a stack of parchment and ink on one side. |
| **Raw Aether Crystal Cluster** | Jagged, unrefined pile of [[aether-crystal\|Aether Crystals]] embedded in dirt near foundations. |
| **Aspirant's Chalkboard** | Freestanding wooden board covered in chalk diagrams of foundational magic theory. |
| **Wild Aether Bloom Patch** | Untamed clusters of [[aether-bloom\|Aether Blooms]] growing naturally in the grass. |

## Tier 2 — Arcanist level (cultivated, intentional, academic)

| Decoration | Description |
| --- | --- |
| **Faceted Crystal Sconce** | Purely decorative wall attachment with a refined [[faceted-aether-crystal\|Faceted Aether Crystal]] set in iron (non-light-emitting). |
| **Arcanist's Reading Pavilion** | Small open-air wooden canopy covering a high-quality desk and reading chair. |
| **Aether-Laced Topiary** | Bushes trimmed into geometric shapes (spheres, diamonds, pyramids) reflecting the mathematical bent of the Arcanists. |
| **Aetherium Archive Shelves** | Modular bookshelves placed against exterior walls under porches; represent [[arcane-lore\|Arcane Lore]] overflow. |

## Tier 3-5 — Loremaster level / grand campus (premium, anti-gravity, prestige)

| Decoration | Description |
| --- | --- |
| **Floating Arcane Rune** | Static anti-gravity stone rune held aloft by the unaligned power of charged [[arcane-pure-anchorstone\|Arcane Pure Anchorstones]]. |
| **Loremaster's Lectern** | Prestigious carved stone podium for outdoor academic discourse. |
| **Grand Orrery Model** | Large metallic decorative cosmos model for the [[arcane-lyceum\|Arcane Lyceum]] courtyards. |
| **Aetherial Fountain** | Stone water feature with water cascading over a central, massive Faceted Aether Crystal. |

## First-pass candidates not in the final roster (paper trail)

NotebookLM's first iteration included several items that didn't survive the cleaner second pass. Recorded here in case any are picked back up:

- **Aether Bloom Ivy, Wild** + **Aether Bloom Ivy, Trimmed** — wall-attachable ivy variants for T1 / T2.
- **Potted Aether Fern** — T1 doorway planter.
- **Scholar's Clothesline** — T1, civilian counterpart to the Castle's "Warlike Clothesline".
- **Cultivated Aether Bloom Planter** — T2 (likely consolidated into the [[aether-bloom-garden|Aether Bloom Garden]] planter family).
- **Aetherwood Sapling** — T2 young tree with light-purple/teal foliage (matures into the [[sacred-grove-decorations|Sacred Grove]]'s Ancient Aetherwood Tree at T3+).
- **Stone Pedestal with Astrolabe** — T2 academic instrument (possibly absorbed into the T3-5 Grand Orrery Model).
- **Specialized Bloom Beds (per-path color variants)** — T3 per-specialization variants moved to per-expansion design.
- **Hovering Crystal Accent** — small floating crystal shards for roof peaks.

## Constraints inherited from other clusters

- **No custom light sources.** The Floating Arcane Rune is anti-gravity (held aloft) but **not** emissive — it doesn't glow. If the design later wants a glowing variant, it must use the vertex-color / HDR-RGBA workaround. See [[foundation-aesthetic-reference#Vanilla style rules (engine-aware)|vanilla style rules]] and [[3d-modeling-pipeline#Emissive treatment — vertex colors / HDR-RGBA (no light sources)|the emissive treatment note]].
- **Charged Anchorstones drive the T3-5 anti-gravity decorations.** The Floating Arcane Rune is the first concrete demonstration of the [[artificer|Artificer]] pivot's premium-decoration use-case.
