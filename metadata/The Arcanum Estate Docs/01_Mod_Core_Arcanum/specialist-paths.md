# Specialist Paths

**The specialist paths** are the four expansion specializations that an Arcanist can branch into: Mage ([[atheneum-tower]]), Paladin ([[citadel-of-light]]), Druid ([[sacred-grove]]), and Sorcerer ([[bloodforged-spire]]). Each is delivered as a separate optional mod that depends on the Core Arcanum mod.

For full context, see [[aetherian-progression]].
