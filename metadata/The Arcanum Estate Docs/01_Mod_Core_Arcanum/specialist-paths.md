# Specialist Paths

**The specialist paths** are the four expansion specializations that an Arcanist can branch into: Mage ([[_atheneum-tower]]), Paladin ([[_citadel-of-light]]), Druid ([[_sacred-grove]]), and Sorcerer ([[_bloodforged-spire]]). Each is delivered as a separate optional mod that depends on the Core Arcanum mod.

For full context, see [[aetherian-progression]].
