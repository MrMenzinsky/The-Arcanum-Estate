# Apothecary

**Apothecary** is a Tier-2 production sub-building where **Aetherial Elixirs** are brewed. Recipe: **Aether Blooms** (gathered from [[aether-bloom-garden|Aether Bloom Garden]] beds) + vanilla **Berries / Herbs** (Labor / Clergy estates).
