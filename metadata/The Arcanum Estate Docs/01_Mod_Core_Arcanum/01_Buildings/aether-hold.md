# Aether Hold

**Aether Hold** is a Tier-1/T2 storage sub-building of the Aethercourt. Stores the estate's physical resources — **Aether Crystal**, **Faceted Aether Crystal**, and any future material components.

Backup name reserved: **Materia Reserve**.

Paired with the **Archive** (intellectual-resource storage) — the split mirrors the knowledge/matter axis that runs through [[aetherian-progression|status/profession theory-vs-practice]].
