# Archive

**Archive** is a Tier-1/T2 storage sub-building of the Aethercourt. Stores the estate's intellectual resources — **Glyphs** and **Arcane Lore**.

Single-noun naming kept for the scholarly tone. Naming alternatives considered and rejected: **Repository** and **Registrum** (both too clerical).

Paired with the **Aether Hold** (physical-resource storage) — the split mirrors the broader knowledge/matter axis that runs through [[aetherian-progression|status/profession theory-vs-practice]].

For full context, see [[core-buildings]].
