# Lapidary

**Lapidary** is the Tier-2 sub-building inside the Aethercourt where Lapidarists refine raw Aether Crystal into Faceted Aether Crystal.

**Dual-resource output (Apiary pattern):** the Lapidary produces **both** Faceted Aether Crystal (primary) **and** [[aether-crystal-dust|Aether Crystal Dust]] (byproduct) per refining cycle. Pattern after the vanilla Apiary / Beekeeper (Wax + Honey) using `COMP_WORKPLACE` dual-resource output logic. Verifying that filling one output's storage does not block the other is a developer task — see [[master-to-do]] Lua / code section.

For full context, see [[core-buildings]].
