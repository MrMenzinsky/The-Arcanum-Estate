# Aether Bloom Garden

**Aether Bloom Garden** is a Tier-1 custom sub-building category for cultivating **Aether Blooms** within the Aethercourt monument grounds. Modelled on the vanilla Monastery's modular **Herb Garden** and **Berry Garden** patterns.

The Aether Bloom Garden category is a *collection* of building parts rather than a single building:

| Part | Role |
| --- | --- |
| **Aether Bloom Planter, Square** | Production tile — Aether Blooms grow here |
| **Aether Bloom Planter, Round** | Production tile (alternate shape) |
| **Aether Bloom Planter, Trellis** | Production tile (alternate shape) |
| **Aether Bloom Garden Hut** | Resource depot — collects the harvested Aether Blooms |

Construction cost: the planter beds are built mostly out of **Aether Crystals** — a deliberate early-game sink for raw crystals before the Lapidary comes online at T2.

Tier placement (T1 planters + Garden Hut → T2 [[apothecary|Apothecary]] consumer) mirrors the Monastery's T1 Herb / Berry Garden → T2 production-building flow.

Per [[dh-notebooklm-tier1-room-parts]] the unique-naming pass that locked the Aethercourt's 8 Tier 1 Room parts did NOT cover this custom category — the planter-and-hut names above are NotebookLM's first-pass suggestions, **not Anton-locked**. A future unique-naming pass should revisit them.
