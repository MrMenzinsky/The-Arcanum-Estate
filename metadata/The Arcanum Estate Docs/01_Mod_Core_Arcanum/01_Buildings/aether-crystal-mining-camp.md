# Aether Crystal Mining Camp

**Aether Crystal Mining Camp** is the standalone external building where Serfs mine raw Aether Crystal. It sits **outside** the Aethercourt — paralleling vanilla resource camps (Stonecutter, Lumber).

**Two-stage mining progression** (mirrors vanilla Stone):

- **Tier 1 — Mining Camp + surface nodes.** Workers extract raw Aether Crystal from surface nodes. Sufficient for the early game and the [[lapidary|Lapidary]]'s base demand.
- **Tier 2 — Prospecting / deep-node mining.** Players unlock the ability to work prospecting (underground) Aether Crystal nodes for deeper, more efficient mining. Scales raw-crystal output to feed both the [[lapidary|Lapidary]] and the T3 [[artificer|Artificer]] without starving either.

**Open question:** the T2 prospecting upgrade may be implemented as either (a) a separate **Aether Crystal Mine** building (mirroring vanilla's Stonecutter Camp → Quarry two-building split) or (b) an upgrade to this same Mining Camp. Anton's L1217 framing said "mines that unlock at tier 2" implying a separate building; the T2 building was never explicitly named. See [[master-to-do]] forgotten-items.
