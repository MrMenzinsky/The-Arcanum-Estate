# Loremaster

**Loremaster** is the Tier 3 Aetherian villager status, promoted from Arcanist. Loremasters work at the **Arcane Lyceum** and deliver the **Lecture Service** that fulfils the **Discourse** need for all T2+ Aetherians and specialists.

For full context, see [[aetherian-progression]].
