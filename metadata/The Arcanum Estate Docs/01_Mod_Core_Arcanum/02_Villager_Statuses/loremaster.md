# Loremaster

**Loremaster** is the Tier 3 Aetherian villager status, promoted from Arcanist. Loremasters have **two viable workplaces**:

- **Primary:** [[arcane-lyceum|Arcane Lyceum]] — delivers the **Lecture Service** that fulfils the **Discourse** need for all T2+ Aetherians and specialists.
- **Secondary:** [[aether-bindery|Aether Bindery]] — works as a [[tomebinder|Tomebinder]] producing **Enchanted Tomes** for high-value export. Keeps Loremasters economically useful once village Discourse is fully met.

For full context, see [[aetherian-progression]].
