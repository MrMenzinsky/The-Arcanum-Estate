# Aetherian

**Aetherians** is the collective term for the population of the Arcanum Estate — every villager whose status is Aspirant, Arcanist, Loremaster, or any specialization (Mage, Paladin, Druid, Sorcerer).

For full context, see [[estate-identity]].
