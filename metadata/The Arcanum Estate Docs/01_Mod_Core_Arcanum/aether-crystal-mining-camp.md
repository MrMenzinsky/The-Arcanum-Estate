# Aether Crystal Mining Camp

**Aether Crystal Mining Camp** is the standalone external building where Serfs mine raw Aether Crystal. It sits **outside** the Aethercourt — paralleling vanilla resource camps (Stonecutter, Lumber). Tier 1.
