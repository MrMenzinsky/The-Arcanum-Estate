# Aetherium

**Aetherium** is the Tier-2 sub-building inside the Aethercourt where Arcanists work as Casters. The name surfaced during Aethercourt naming as too fantastical for the monument itself, but was reassigned to this sub-building where its mystical tone fits.

For full context, see [[core-buildings]].
