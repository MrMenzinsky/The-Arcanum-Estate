# Mage Ranks — Decision Log

## Final state

The Mage path uses an academic-hierarchy progression (High / Grand / Arch) to
denote escalating elemental mastery.

| Tier | Rank | Lvl Range | Note |
| --- | --- | --- | --- |
| Tier 1 | **Mage** | 1–5 | Entry-level specialist (specialization start). |
| Tier 2 | **High Mage** | 6–10 | Mastery of the Work Profession (e.g. Wind Weaver). |
| Tier 3 | **Grand Mage** | 11–15 | Intermediate optional rank. |
| Tier 4 | **Archmage** | 16+ (hidden) | Hidden, quest-unlocked apex rank. |

## Iteration history

The Mage path was the **template** for the other three — Anton already had the
working pair *Mage → Archmage* before the rank discussion started, and the
intermediate slots filled in cleanly on the first pass.

- L2604–2624 — initial proposal table: Mage / High Paladin / Elder Druid / Grand Sorcerer suggested for Tier 2 across all paths.
- L2629–2632 — Anton proposes the four-tier framework with Mage → High Mage → (Grand/Master Mage?) → Archmage.
- L2641–2667 — Gemini locks the four-tier structure; recommends Grand Mage over Master Mage for symmetry.
- L2681–2698 — formal Mage tier table presented.
- L2702–2706 — Anton: "I'm happy with these for the Mages." Locked in one pass.
- L3263–3268 — final consolidated rank table across all four paths confirms Mage progression unchanged from this lock-in.

No further iteration needed.

## Abandoned options

- **Arch Mage** (two words) — superseded by single-word **Archmage** as the canonical spelling.
- **Master Mage** (Tier 3) — rejected in favor of **Grand Mage** for the cleaner High → Grand → Arch ladder.
