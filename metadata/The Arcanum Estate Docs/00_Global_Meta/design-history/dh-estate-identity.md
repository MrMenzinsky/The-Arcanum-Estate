# Estate Identity — Decision Log

## Final state
- Estate name: The Arcanum Estate
- Splendor color: metallic purple (lavender)
- Base unit: Scholar (later evolved — see [[dh-aetherian-progression]])
- Base resource: Arcane Lore (parallel to Royal Treasures / Piety)
- Core fantasy: fourth estate alongside Labor / Clergy / Kingdom; intellectual + scientific magic rooted in scholarship
- Scholar branches into four specializations: Mage/Wizard, Paladin, Druid, Warlock/Sorcerer (mirrors Kingdom's branching promotion structure)

## Iteration history
- L92-107: Initial pitch — fourth "magic estate" built on Scholar base unit with branching specializations (Mage, Paladin, Druid, Warlock), parallel to Kingdom militia-to-knight promotion.
- L116-118: Scholar as educated Labor villager, assigned to Academy/Grand Library, producing Arcane Lore. Resource name "Arcane Lore" surfaced here and stuck.
- L181-182: Anton pivots away from buildings back to estate identity — frames color choice against existing estates (Labor yellow/gold, Clergy silver, Kingdom orange/bronze). Proposes metallic blue or purple.
- L213-217: Purple locked. Reasoning: metallic blue too easily confused with Clergy silver for colorblind / low-vision players. Accessibility-driven decision.
- L219-233: Gemini proposes initial buildings (Scriptorium + Academy) right after color lock — Anton defers both at L237-238: Scriptorium name collides with an existing Monastery sub-building; "Academy I like more, though I don't know if that name is suitable for the entire monument." Forward-pointer to [[dh-the-aethercourt]] and [[dh-core-buildings]].
- L237-239: Name discussion opened. Anton brings "Arcane" / "Arcanum" as starting points.
- L261-276: Variant survey (Arcana, Arcane Order, Arcane Council, Great Arcana, Arcane Conclave) — none chosen.
- L280-303: Naming locked via consistency analysis with existing estates. Labor / Clergy / Kingdom are all singular collective nouns. "Arcane" is an adjective → outlier. "Arcanum" is a noun → fits the pattern. The Arcanum Estate wins.
- L307-311: Full lock — "The Arcanum Estate, metallic purple splendor."

## Abandoned options
- Deep sapphire blue splendor — rejected for accessibility (too close to Clergy silver under color-vision impairment).
- Blue-purple gradient — Gemini's preferred suggestion; rejected implicitly when Anton chose flat purple for distinctness.
- "The Arcane Estate" — rejected: adjective, breaks the noun pattern set by Labor/Clergy/Kingdom.
- "The Scholarly Estate" — rejected despite strong fit with Scholar base unit; "Arcane" branding preferred.
- "The Mystical Estate" / "The Esoteric Estate" — considered, not chosen.
- "The Arcane Order / Council / Conclave" — too specific; names a faction, not a societal pillar.
- "The Arcana Estate" — close runner-up; lost to Arcanum because Labor/Clergy read as singular collective nouns, not plurals.
